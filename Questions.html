Questions


1) Le Html soit HyperText Markup est un langage de code, de balisage. Il permet de creer des pages web grâce à des balises et des éléments.


2) Le Css acronyme de Cascading Style Sheets est un langage de style. Il est utilisé pour contrôler l'apparence visuelle d'une page web.


3) Pour lire une page web il faut utilisé un navigateur web comme Google ou Brave. Pour modifier ou creer une page on utilise un éditeur de code tels que Visual studio code, Sublime text ou Notepad++


4) Une balise est un élément utilisé pour marquer et structurer le contenu d'une page web. Une balise est composé de <>. J'ai utilisé de nombreuses balises : p pour un paragraphe ; h1 ou h2 pour des titres de différentes tailles; a pour des liens hypertexte; img pour des images; ul et li pour des listes ou encore section pour creer des sections


5) L'en-tête contient des informations sur la page elle-même les méta-données : titre, langue, description de la page,feuille de style à utiliser… La balise la limitant est head


6) Dans le corps du html il y a tous les éléments de notre site. La balise div le délimite.


7) Les pages web sont en général stockées dans des serveurs web. On y accède grâce à une url.
